# CheckinBooking Platform

Monorepo containing:

- **backend/** — Laravel API shared by both frontends (hotel booking + platform admin), branch history preserved from the original `checking-Booking` repo.
- **hotel-frontend/** — Angular app for hotel staff (reservations, front desk, settings).
- **platform-admin/** — Standalone Angular app for onboarding and managing SaaS tenants (subscriptions, branches, buildings, platform operator accounts).

Each app has its own README/setup instructions in its own folder.
